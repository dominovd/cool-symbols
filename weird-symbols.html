Compatibility notes

This collection uses plain Unicode text, so the symbols work in most modern apps. Rare or decorative characters can look different across devices or appear as boxes on older fonts. For maximum compatibility, test the symbol on mobile before using it in a permanent username or profile.

Frequently asked questions

Why do weird symbols break more often?
Many weird symbols come from rare Unicode blocks that not every device font supports. Common symbols render more reliably.
Are weird symbols searchable?
Some are searchable as Unicode characters, but many are hard to type or name. Copy-paste is usually the easiest way to use them.
Can weird symbols be used in usernames?
They may work in display names, but many platforms reject rare Unicode in account handles.
