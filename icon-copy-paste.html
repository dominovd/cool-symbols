How to use icon copy paste

Copy text icons when you need the feel of an icon without uploading an SVG or image. Use arrows for calls-to-action, checks for benefits, shapes for bullets, hearts and stars for decoration, and small signs for labels in bios or documents.

Where icon copy paste shine

Calls to action

Use ➜, ➤, or → before links, buttons, and short instructions.

Lists and feature bullets

Use ✓, ◆, ◉, or ✦ to make plain text easier to scan.

Profile labels

Add small icons next to location, music, contact, hobbies, or links in a social bio.

No-image UI notes

Text icons work in places where images or custom icon fonts are not allowed.

Frequently asked questions

Are text icons real icons?
They are Unicode text characters that look like icons. They copy, paste, resize, and inherit color like text.
Do text icons work in HTML?
Yes. You can paste Unicode text icons directly into HTML, Markdown, comments, and text fields.
Why use text icons instead of emoji?
Text icons are often cleaner, monochrome, and easier to match with surrounding text than colorful emoji.
